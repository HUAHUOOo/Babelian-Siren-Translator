# APK 字形与图标素材

来源：用户提供的 `ato_android_2026_09_23_01.apk`。原文件的 SHA256、提取日期、文件清单和逐文件校验值见 [manifest.json](manifest.json)。授权状态见 [NOTICE.md](NOTICE.md)。

| 目录 | 内容 | 当前用途 |
| --- | --- | --- |
| `fonts/` | Babelian_Cypher.ttf 原始字体 | 保留原始字形来源，不作为网页外部字体加载 |
| `babelian/` | 58组SVG／PNG、字符表、字体映射、58字形显示配置、580个多分辨率识别变体 | 构建时内嵌显示配置和辅助模板，下载页面即可离线使用 |
| `siren/` | 26小螺旋及1大螺旋、24段有序碰撞几何、起始位置、静态分析记录 | 供校准和研究；不替代当前细像素读序 |
| `icons/` | 189个命名图标及索引 | 可查找和复用；不自动增加界面入口 |

字体输入中的1、2、3、4、5、?分别对应整词THE、A、AND、OF、OR、!?；这里只说明字体码位，**不会把用户正常输入的数字自动转换成这些词**。真实对应以`babelian/characters.json`及显示配置中的不透明ID为准。

塞壬语的数组索引保留APK顺序，不等于英文A—Z排序。Unity局部坐标和左下角枢轴不能直接当作PNG左上角坐标使用。`recovered-rules.json`为静态分析结果，含尚未验证的分支，不是完整Unity物理实现。

未收录整APK、运行库、反编译程序、其他排版字体、故事正文、卡牌原图、私人截图、账号或存档。构建只读取已校验的两份巴别语配置，原有91张识别PNG不被替换。
