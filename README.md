# 巴别语与塞壬语翻译器 · Babelian & Siren Translator

《永世侵入：奥德赛》（Aeon Trespass: Odyssey）的非官方密码辅助工具：用字形书写、识别截图、复核字母，并整理成英文或翻译为中文。生成与识别可离线使用，中文机翻为可选联网功能。

## 快速开始

1. 在仓库页面选择 **Code → Download ZIP**，下载并解压。
2. 用浏览器打开文件夹中的 `index.html`，无需安装程序、注册账号或配置服务器。
3. 首页有四个入口：**巴别语生成、巴别语翻译、塞壬语生成、塞壬语翻译**。生成用于书写，翻译直接进入截图识别与复核。

界面沿用 ATO Assistant 的纸底、直角细边框与中文字体风格：巴别语采用故事集 IV 的米金配色，塞壬语采用故事集 V 的海蓝配色。切换入口只改变界面，不清空已有工作。

两种翻译页的初始布局一致：只显示语言标题、**粘贴图片／选择图片**及格式提示。载图后再显示预览和识别操作，有结果后显示复核等工具；已有图片和结果不会因返回首页而被清空。若浏览器不允许按钮读取剪贴板，可使用Ctrl+V或选择文件。

### 巴别语：直接书写或识别

首次使用已载入所提供字形表的默认对应，可直接开始。已有自定义配置（包括空白配置）不会被覆盖；如需切换，在“部件筛选与映射”中点击“载入默认配置”。

1. 默认配置包含26个大写、26个小写字母及6个词语/符号。需要调整时，进入 **部件筛选与映射**；仍支持新建空白配置和导入自己的对应表。
2. **书写**：从首页进入 **巴别语生成**，点击字形键盘或使用电脑键盘输入，上方显示巴别语、下方显示英文。空格只出现在英文中，不增加字形间距。
3. **识别截图**：从首页进入 **巴别语翻译**，选择、粘贴或拖入图片。页面会在证据充分时建议文字选区，并提示低对比等问题；检查金色框是否完整，点击 **识别所选区域**。仍可手动框选或撤回自动选区，识别出的字形按当前映射转成英文。
4. 识别后直接看英文；待确认项先显示候选文字，仅无候选时显示 `[?]`。需要校正时展开逐字复核，点击字形查看详情；确认或点空白处后关闭。可复制英文，或追加到书写区。
5. 当前简洁界面不显示识别工作保存／载入和校正历史。刷新或关闭前请复制所需文本，或主动追加到书写区；不会自动保存截图。

点击整理英文中的单词，可看到对应原图；点击逐字英文可定位一个字形。此时不打开复核、不改结果，点 **复核此处** 或原图蓝框才进入复核。允许的空格和标点修改仍能定位；改动字母或映射导致对应关系失效时会停止定位，不猜测位置。

当前页面已内置完整矢量显示和多分辨率辅助模板，无需另外设置。生成页提供 **下载 PNG／下载 SVG**，键盘及候选预览使用矢量显示；SVG字形为路径，英文为可编辑文本。原PNG识别模板保持，辅助模板不提高自动确认门槛，也不替代人工复核。

### 塞壬语：生成螺旋或识别截图

- **生成**：从首页进入 **塞壬语生成**，添加大螺旋，再点击 **新增小螺旋** 展开字形键盘。每组最多6个字母，可拖动调整位置，也可批量生成。
- **识别**：从首页进入 **塞壬语翻译**，粘贴或选择图片，点击 **开始识别**。完成后直接显示英文和分词建议；逐字原文、完整复核区默认收起。
- **原图定位**：点击英文可对照对应字形，支持跨组单词和数字词转换后的数字；点击 **复核此处** 或对照图中的小螺旋可直接调节。查看或点选不会确认字母。改动文字内容而无法可靠对应时停止定位。
- **逐组预览**：每完成一组就显示原图小图和当前英文。中间预览不改已有工作；全部完成后统一加入。取消后可选择 **保留已完成组**，可一次撤销；换图、离开或工作已修改时不采用旧预览。
- **重复识别**：相同图片、模板和识别条件可复用本页内的计算；取消后重试也能复用已完成组。缓存只在内存中，容量有上限，刷新后失效；不会保存或自动恢复人工校正，也不改变原来的加入／替换规则。
- **内存与撤销**：旧截图会按需回收，撤销时恢复原图；历史同时限制条数和容量。刷新或关闭前仍需保存工作，这不是自动保存功能。
- **简洁入口**：无图片和解读工作时只显示图片入口；载入后显示预览／识别，有分组后再显示结果与复核。漏组补扫、待复核导航与精确调节窗口保留。
- **复核**：点击 **展开复核**。点击画布中的小螺旋或下方字母按钮，直接打开精确调节窗口（含“？”和锁定项），不再另设“精确调节”按钮。默认 **查看** 模式，放大后拖动画面；只有切到 **调整** 才能拖动字形。拖动不会自动弹窗。可用适应窗口／2倍／4倍查看、叠加模板；标记最内侧交点时按住微调放大镜准星，松手记录，Esc取消。缩放和打开窗口不改变识别数据。
- **其他操作**：删除、调整组顺序、重新识别此组等放在 **更多操作** 中；精确调节窗口底部固定提供上一项／下一项／完成调节。“完成调节”只关闭窗口，不代替正确性确认。
- **读序演示**：展开画布下的 **查看读序演示**，逐步或播放查看当前读取顺序；不移动字形、不确认候选，未定位项不参与编号。换组、修改或离开页面时停止播放。
- **差异对照**：在画布下展开 **整组重建／差异对照**，查看原图、按当前姿态重建的图形及红／蓝差异。红色是未解释笔画，蓝色是模板多出笔画；噪声、缩放或邻组图形也会产生颜色，不代表识别错误或正确率。
- **导出**：生成的螺旋可导出整幅PNG；英文可复制、生成分词断句建议或机翻。



## 识别不准时怎么办？

优先使用清晰、端正、只含密码文字的图片，尽量避开标题、插画和英文说明。

- 巴别语的 `[?]` 表示无候选，橙色项虽显示候选文字仍待确认；`[未映射]` 表示未设置英文对应。塞壬语的 `[?]` 仍表示未知项。
- 巴别语分割有误时，在逐字复核中展开 **分割不正确？**，可拆分、合并或重新框选；塞壬语可用 **精确调节** 对照候选、位置和交点。
- 匹配分数不是正确率。工具不会按词义补齐未知字母，分词和机翻也需要核对。

## 保存与隐私

刷新或关闭前请留意：以下内容使用不同的保存方式。

| 内容 | 保存方式 |
| --- | --- |
| 巴别语映射与书写草稿 | 独立版保存在当前浏览器。已有映射和书写区保存方式不变；当前简洁界面不显示工作备份栏。 |
| 巴别语截图、校正与整理草稿 | 仅在当前页面保留；刷新或关闭前复制文本，或主动追加英文到书写区。当前不显示识别工作保存／载入入口。 |
| 塞壬语画布与截图解读 | 在生成、解读模式下分别点击 **保存塞壬语工作**。整理英文和译文请另外复制。 |

截图识别在本机完成，不上传图片。只有同意并主动点击中文机翻时，当前整理后的英文才会发送给 MyMemory；采用你调整后的空格和标点。机翻为第三方服务，请勿发送敏感内容。

## 素材与声明

本项目与游戏发行方无隶属关系，游戏名称及字形素材的权利归各自权利人所有。离线分词使用 Wordninja 的词频数据，并保留其 [MIT 许可声明](src/wordninja-LICENSE.txt)。仓库不包含私人存档、剧情书或卡牌原图。

中文游戏名及“剧情书”等术语依据所提供的官方中文规则书核对，并参照前三部官方中文故事集复核。官方正文使用“海妖”作为这类生物的名称，例如《无情烈日》印刷页120的航标梦境卷轴7；这不等于已确认密码语言的正式译名。已核对的资料尚未确认“巴别语／塞壬语”的正式中文名，因此工具名称、字形映射和英文转写保持不变。

中文机翻不是官方译文，不会自动套用或补写官方剧情。游戏专名及规则应对照对应的官方中文剧情书和规则书；本次提供的官方故事集仅覆盖I–III，不能据此将IV–V的译述标为官方译文。
