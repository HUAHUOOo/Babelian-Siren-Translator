# 巴别语与塞壬语翻译器 · Babelian & Siren Translator

《永世侵入：奥德赛》（Aeon Trespass: Odyssey）的非官方密码辅助工具：用字形书写、识别截图、复核字母，并整理成英文或翻译为中文。生成与识别可离线使用，中文机翻为可选联网功能。

## 快速开始

1. 在仓库页面选择 **Code → Download ZIP**，下载并解压。
2. 用浏览器打开文件夹中的 `index.html`，无需安装程序、注册账号或配置服务器。
3. 首页有四个入口：**巴别语生成、巴别语翻译、塞壬语生成、塞壬语翻译**。生成用于书写，翻译直接进入截图识别与复核。

界面沿用 ATO Assistant 的纸底、直角细边框与中文字体风格：巴别语采用故事集 IV 的米金配色，塞壬语采用故事集 V 的海蓝配色。切换入口只改变界面，不清空已有工作。

### 巴别语：直接书写或识别

首次使用已载入所提供字形表的默认对应，可直接开始。已有自定义配置（包括空白配置）不会被覆盖；如需切换，在“部件筛选与映射”中点击“载入默认配置”。

1. 默认配置包含26个大写、26个小写字母及6个词语/符号。需要调整时，进入 **部件筛选与映射**；仍支持新建空白配置和导入自己的对应表。
2. **书写**：从首页进入 **巴别语生成**，点击字形键盘或使用电脑键盘输入，上方显示巴别语、下方显示英文。空格只出现在英文中，不增加字形间距。
3. **识别截图**：从首页进入 **巴别语翻译**，选择、粘贴或拖入图片，框住巴别语区域，点击 **识别所选区域**。识别出的字形按当前映射转成英文；翻译页也能编辑映射。
4. 识别后直接看英文；待确认项先显示候选文字，仅无候选时显示 `[?]`。需要校正时展开逐字复核，点击字形查看详情；确认或点空白处后关闭。可复制英文，或追加到书写区。

### 塞壬语：生成螺旋或识别截图

- **生成**：从首页进入 **塞壬语生成**，添加大螺旋，再点击 **新增其他小螺旋** 展开字形键盘。每组最多6个字母，可拖动调整位置，也可批量生成。
- **识别**：从首页进入 **塞壬语翻译**，粘贴或选择图片，点击 **自动分割并匹配**。
- **复核**：选中小螺旋，对照原图与候选字形。需要时使用 **精确调节**、锁定位置或删除误识别项。
- **导出**：生成的螺旋可导出整幅PNG；英文可复制、生成分词断句建议或机翻。



## 识别不准时怎么办？

优先使用清晰、端正、只含密码文字的图片，尽量避开标题、插画和英文说明。

- 巴别语的 `[?]` 表示无候选，橙色项虽显示候选文字仍待确认；`[未映射]` 表示未设置英文对应。塞壬语的 `[?]` 仍表示未知项。
- 可以使用 **疑难字形深度识别**（巴别语）或 **疑难区域深度识别**（塞壬语）多比较一轮，再手动确认候选。
- 匹配分数不是正确率。工具不会按词义补齐未知字母，分词和机翻也需要核对。
- 核实后的字形可以加入 **校正样本库**，方便留存与后续改进；目前不会自动训练或立即改变识别结果。

## 保存与隐私

刷新或关闭前请留意：以下内容使用不同的保存方式。

| 内容 | 保存方式 |
| --- | --- |
| 巴别语映射与书写草稿 | 独立版保存在当前浏览器；用 **下载完整工作备份** 导出。换浏览器、设备或文件地址前请备份。 |
| 巴别语截图识别结果 | 不在完整工作备份中；需要的英文请复制，或追加到书写区后保存。 |
| 塞壬语画布与截图解读 | 在生成、解读模式下分别点击 **保存塞壬语工作**。整理英文和译文请另外复制。 |
| 校正样本库 | 单独点击 **导出全部样本**，以后可导入继续使用。 |

截图识别在本机完成，不上传图片。只有同意并主动点击中文机翻时，当前整理后的英文才会发送给 MyMemory；采用你调整后的空格和标点。机翻为第三方服务，请勿发送敏感内容。

## 素材与声明

本项目与游戏发行方无隶属关系，游戏名称及字形素材的权利归各自权利人所有。离线分词使用 Wordninja 的词频数据，并保留其 [MIT 许可声明](src/wordninja-LICENSE.txt)。仓库不包含私人存档、剧情书或卡牌原图。

中文游戏名及“剧情书”等术语依据所提供的官方中文规则书核对，并参照前三部官方中文故事集复核。官方正文使用“海妖”作为这类生物的名称，例如《无情烈日》印刷页120的航标梦境卷轴7；这不等于已确认密码语言的正式译名。已核对的资料尚未确认“巴别语／塞壬语”的正式中文名，因此工具名称、字形映射和英文转写保持不变。

中文机翻不是官方译文，不会自动套用或补写官方剧情。游戏专名及规则应对照对应的官方中文剧情书和规则书；本次提供的官方故事集仅覆盖I–III，不能据此将IV–V的译述标为官方译文。
