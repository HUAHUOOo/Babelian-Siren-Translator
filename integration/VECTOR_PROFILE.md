# 可选本机矢量资源

本功能基于1.11.3重新接入，不恢复远端已移除的工作保存、校正历史或样本库界面。公开源码只包含通用算法，独立页和ATO包只带既有91张PNG；提取字体、形状数据和私人图片留在仓库外。

## 显示与导出

页面初始化前可提供`globalThis.BabelianVectorArtwork`：`{version:1,glyphs:{不透明ID:{viewBox:[x,y,w,h],matrix:[a,b,c,d,e,f],d:路径}}}`，须覆盖全部字形。只接收有限数值和受限路径字符，不接收任意SVG、脚本、事件属性或外部图片。无素材或验证失败时回退原显示。

生成页、键盘、映射和候选预览使用独立的`displayGlyphs`；原始`glyphs`仍用于图像识别。宽高框和PNG排版保持，PNG可从SVG源绘制；浏览器的SVG导出包含自有路径和内部引用，英文是转义的可编辑系统字体文本，不是字体轮廓。无完整素材时隐藏SVG按钮；Android不改变PNG／JSON桥接，也不显示SVG入口。

## 识别辅助

`globalThis.BabelianVectorTemplateProfile`是另一个对象，格式`{version:1,variants:[...]}`。每项包含不透明ID、目标高度、比例、32行位图及128字的细位图和计数，最多1024项。公开构建不提供此数据。

原分割、阈值及同页校正完整运行后，只检查高度至少16像素、近分且未确认的候选。原最佳候选须与当前结果一致且分数至少0.72、前两名差小于0.035；只比较距最佳不超过0.025的原生前五名。所有竞争者均需两个分辨率，取较低支持度；至少0.94且领先0.06，并在两个阈值下支持同一新候选才可改字。

不改识别框，不插删字形，不提高自动确认；手动阈值、粗比对及缺少素材时不执行。显示对象不会传给识别Worker，两个对象也不会写进映射或存档。现有默认自动识别参数不变。

提取成功不等于获得再分发许可，本机资源不能直接作为公开构建提交。公开测试使用匿名路径／重复模板，不包含提取轮廓、私人译文或截图。
